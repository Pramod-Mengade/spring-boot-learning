# Spring Core

This module covers the core features of the Spring Framework, including Dependency Injection (DI), Inversion of Control (IoC), bean management, and Java-based configuration.

---

## 📚 Projects

| Project | Concept |
|---------|---------|
| 01-constructor-injection | Constructor-based Dependency Injection |
| 02-component-scanning | Component Scanning |
| 03-setter-injection | Setter-based Dependency Injection |
| 04-qualifier-demo | Using `@Qualifier` |
| 05-primary-demo | Using `@Primary` |
| 06-lazy-initialization-demo | Lazy Bean Initialization |
| 07-bean-scope-demo | Bean Scopes |
| 08-bean-lifecycle-methods | Bean Lifecycle Methods |
| 09-java-config-demo | Java-based Configuration |

---

## 🎯 Learning Objectives

- Understand IoC and Dependency Injection
- Configure beans using annotations
- Manage bean lifecycle
- Work with bean scopes
- Resolve dependency conflicts
- Configure Spring using Java classes
