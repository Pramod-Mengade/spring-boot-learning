# Spring Boot Overview

This module introduces the fundamentals of Spring Boot and its core features. Each project focuses on a specific concept to build a solid foundation for backend development.

---

## 📚 Projects

| Project | Description |
|---------|-------------|
| 01-spring-boot-demo | Introduction to Spring Boot and project structure |
| 02-dev-tools-demo | Spring Boot DevTools for automatic restart and LiveReload |
| 03-actuator-demo | Monitoring and management using Spring Boot Actuator |
| 04-actuator-security-demo | Securing Actuator endpoints |
| 05-command-line-demo | Using `CommandLineRunner` to execute code at startup |
| 06-properties-demo | External configuration with `application.properties` |

---

## 🎯 Learning Objectives

- Understand Spring Boot architecture
- Create a Spring Boot application
- Use Spring Boot DevTools
- Monitor applications with Actuator
- Execute startup logic using `CommandLineRunner`
- Manage application configuration using properties

---

## 🛠 Technologies Used

- Java
- Spring Boot
- Maven
- Spring Boot Actuator
- Spring Boot DevTools
