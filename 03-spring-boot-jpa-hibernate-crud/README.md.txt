# Spring Boot JPA & Hibernate CRUD

This module introduces Hibernate ORM and Spring Data JPA for database interaction. It demonstrates how to build CRUD applications using MySQL and Hibernate.

---

## 📚 Projects

| Project | Description |
|---------|-------------|
| 00-starter-sql-scripts | SQL scripts for creating the database and sample data |
| 01-crud-demo-student | CRUD operations using Hibernate and JPA |

---

## 🎯 Learning Objectives

- Understand ORM (Object Relational Mapping)
- Create JPA entities
- Configure Hibernate
- Perform CRUD operations
- Use EntityManager
- Create DAO classes
- Manage transactions
